1 · 两把 key

识别用 Groq,翻译总结用 DeepSeek,都是你自己申请、自己付,这个网站不经手。可以先跳过,用试用额度感受一下。

怎么拿 Groq key(2 分钟)
  1. 打开 console.groq.com,用 Google / GitHub / 邮箱注册。
  2. 左侧菜单 API Keys → Create API Key,名字随便起。
  3. 复制出来粘到上面(只显示一次,丢了就再建一个)。
  4. 免费档每天 8 小时音频,一个人上课够用。
怎么拿 DeepSeek key(3 分钟)
  1. 打开 platform.deepseek.com,手机号注册。
  2. 左侧 充值,充几块钱就够用很久(一小时课约 3–5 毛)。不充值 key 会报「余额不足」。
  3. 左侧 API keys → 创建 API key → 复制粘到上面。

2 · 笔记同步到哪

下课后的笔记是一个 Markdown 文件。选一种方式让它出现在你的 Obsidian 里。

用这里给你的同步文件夹(推荐,最省事)服务器给你开一个私人 WebDAV 文件夹,手机和电脑的 Obsidian 装 Remotely Save 指过来就行。笔记会存在这台服务器上,只有你能访问。
用我自己的 WebDAV(坚果云 / 自建)下课后把笔记推到你的网盘,不经过这里存储。
不同步,结束后手动下载每节课结束页有下载按钮,7 天内都能下。
手机 Obsidian 里怎么配(5 步,只配一次)
  1. Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 浏览,搜 Remotely Save,安装并启用。
  2. 进 Remotely Save 的设置:服务选 WebDAV。
  3. 地址、用户名、密码照上面三行粘进去;远程基础目录 填 tingke。
  4. 点「检查连接」,显示成功。
  5. 回到笔记,点左侧栏的同步按钮。电脑上的 Obsidian 装同一个插件、填同样的内容,两边就同步了。
坚果云怎么拿 WebDAV 密码
  1. 网页登录坚果云 → 右上角头像 → 账户信息 → 安全选项。
  2. 第三方应用管理 → 添加应用 → 生成密码,复制。
  3. 地址填 https://dav.jianguoyun.com/dav ,账号是你的邮箱。
  4. 手机 Obsidian 的 Remotely Save 也填同一套,远程基础目录填 tingke。
